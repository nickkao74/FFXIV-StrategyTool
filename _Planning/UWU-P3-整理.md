## 4. 打法(以逐字稿為主體)

### 4-1 轉場落地(00:07–00:29)

- 泰坦落中央,**距離衰減** → 退到外周最邊緣;伊弗利特的突破極限等衰減結束再撿(**D4**,沿用 P2)。(A)
- 大地之怒:很痛,**仇恨重置**,坦克注意姿態。(A)
- 二連死刑:開滿減傷。(A)

### 4-2 大地之重 → 跳躍(00:36–00:59)

- 大地之重二連:沿泰坦順時針或逆時針躲。(A)
- 泰坦**瞬間轉向** → 往面向方向跳 → 從落點距離衰減 → **往反方向退**。範例:面向 B → 退 D。(A)
- MT 要把泰坦**固定在正中央**,方向才好判斷。(C)
- 場地還寬,不知道躲哪就躲兩點中間。(C)

### 4-3 自滅法(01:13–01:35)(C)

- 「在現在的版本中,在這裡讓人數減少是主流」。
- 第一次大地之重:第 1 下順時針躲開;**MT、補師、法系**去躲第 2 下;**其他 4 人刻意吃重力死掉**。
- 逐字稿原文是「其他四個 DPS」,但存活組已含法系,剩下的 4 人是 **ST + 近戰 ×2 + 遠程物理** → 本攻略寫成 **ST、D1、D2、D3**(本專案 D1/D2 近戰、D3 遠程物理、D4 法系,沿用 P2 的分配)。
- **效果**:岩牢點名「一仇以外隨機 3 人」→ 只剩 H1、H2、D4 → 點名**必定確定**。

### 4-4 大激震(01:35–02:18)

- 衰減後馬上**往泰坦靠近**;原本的安全區會落下岩石。(A)
- 「其中這兩顆岩石必定有一顆是缺角的,靠近泰坦後確認是哪一顆缺角」(C,✅ 截圖 `p3-1`:**中間兩顆隨機缺一顆**)
- 用泰坦的**目標圈**:尖端此時剛好指向場地正中央,站在與紅色圓圈**內側相接**的位置,右邊站這、左邊站那。(C,✅ 截圖 `p3-2`)
- 防擊退無效;擊退前先暈眩。(A)
- 大激震結束後剛才的安全區**馬上又落石** → 往**外周的前方**迴避。(A,對上 BossMod 的「多一顆岩石」)
- 落石落地瞬間也有類似炸彈的即死判定。(C)

**幾何**:見 §4-0。v1 用 14m 推導的落點已作廢。

### 4-5 三連岩牢(02:23–03:51)

- 一仇以外隨機 3 人,點名後約 4 秒拘束。(A)
- 自滅法下:**離泰坦最近的標記站法系,1 號標記站 H1,離最遠的標記站 H2**。(C)
- 擊退後先往外周前方移動,把地裂斬**稍微引導偏一點**;若地裂斬蓋到固定位置,**看詠唱 8 成時衝進去**。(C)
- 以**剛掉下來的岩石**為引爆源,三個岩牢連續爆炸 → 汙泥延伸到泰坦腳下 → 泰坦踩上去覺醒。(A)
- 第 2 次地裂斬:中央側是岩牢爆炸即死範圍,MT 不能靠近中央。(A)
- 岩牢內無敵,不用幫他們閃地裂斬。(C)
- 岩牢期間有全體攻擊:補師要治療;召喚士要在旁邊讀條拉人 → 所以把法系排最前面。(C)
- 復活在**中央偏泰坦**;陣亡者**在第 1 發地裂斬判定結束後再起來**。(C)

**連鎖距離檢查(A 級數字)**:岩石大爆炸 6.3m、石牢爆炸 6m、石牢 R1.8 → 相鄰兩點距離要在 **約 7.8m** 以內才連得上;
D4 那攤汙泥(約 7m)要碰到泰坦(R 4.55m),D4 離泰坦要在約 11.5m 以內。

截圖量到的 D4 / H1 / H2 間距約 8~9.5m,比極限略大(示意圖本身不是精確比例)。

引爆源岩石 = 擊退落點 (−4.4, 8.2),H2 離它 3m。腳本會檢查每一段距離,斷掉就報錯。
