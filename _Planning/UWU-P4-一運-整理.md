## 4. 打法(以逐字稿為主體)

### 4-0 LB 階段(P3 影片後段,C)

- 周圍出現魔導浮游炮 → **法系在中央放 LB** 一網打盡,可能殺不乾淨,大家各自補打;時機約在距離衰減砸下來時,可用巨集對自己放
- **補師 LB**:擊倒結束後馬上放
- **拉哈布雷亞**在中央出現 → 馬上放**近戰 LB**,大家一起補刀;沒有近戰的陣容:法系 LB + 全員爆發藥
- 最後是**坦克 LB**,量表一滿馬上放
- 分配:法系 = **D4**、治療 = **H1**、近戰 = **D1**、坦克 = **MT**(沿用 P1~P3 的分配:D4 法系、D1 近戰;H1 / MT 為本攻略的預設,**待本隊確認**)

### 4-1 登場(00:00–00:59)

- MT 立刻拉穩一仇,ST 維持二仇;兩人都開坦克姿態,只有 MT 挑釁。(C)
- 魔導核爆:很痛的普通全體。(A)
- 吸附式炸彈:附加在一仇**及周圍** → **MT 遠離大部隊單獨吃**。(A)
- 追蹤射線:二仇的中範圍強攻擊 → **ST 在側邊單獨承受**。(A)
- 引爆:**不分攤**,坦克開滿減傷單吃。(C)

### 4-2 追擊之究極幻想(01:00–06:32)

- 出現位置:迦樓羅在**中央附近、標記與標記之間**(4 種);究極神兵與伊弗利特在**斜點**(各 4 種,不重疊);泰坦在**正點偏一點**(8 種)。(C,BossMod 不預測位置)
- 泰坦的地裂斬範圍固定,**剛好打在東南西北偏一點點的位置**。(C,幾何上成立:泰坦在場邊、面向中央時,±45° 的直線正好打到相鄰兩個正點)
- **無視十字**:伊弗利特的十字做好團隊減傷,補師和 DPS 都吃得下;把它當不存在,安全區就很大。(C)
- 流程:先減傷 → 中央集合 → **背對迦樓羅** → 往沒有泰坦的正點走 → 地裂斬貼著預兆線閃 → 究極神兵在附近就往反方向偏一點 → 硬吃十字。(C)
- 三個注意事項:穿過標記直直往外;地裂斬往容易閃的方向、貼著預兆線;吃十字時靠外周。(C)
- 最後飛羽雨:**聽到叫聲再移動**。(A)
- 十字也能完美閃掉,但這段也想**累積 LB 量表**,所以硬吃。(C)

**幾何驗算**(全部是 BossMod 數字):
- 迦樓羅的龍捲外徑 **20m**:迦樓羅在中央偏 4.7m 時,反方向場邊(19.4m)離牠約 23m → **背對迦樓羅走到底就安全**。
- 伊弗利特的衝鋒半寬 **9m**、走斜線 → 正點場邊離斜線 19.4 × sin 45° ≈ 13.7m,安全;十字半寬 **5m**、走正點方向 → **站在正點場邊一定會被十字打到**,所以影片才說「硬吃」。
- 究極神兵的青磷放射 **14m**:究極神兵在斜點場邊時,相鄰正點場邊離牠只有約 14.6m → **剛好在邊緣**,這就是「在附近的話稍微往反方向偏一點」。
- BossMod 的 `P4UltimatePredation` 也把安全點放在**離中心 19m 的圓周**上(`_dodgeRadius = 19`),與影片「往外周走、靠外周邊緣」一致。

### 4-3 一運後半(06:33–10:31)

- 飛羽雨排完後確認方位;**地火小組 2 人往南,其他人往北**。究極神兵在中央出現後,**MT 往東北(A 與 B 之間)拉一步**。(C)
- **伊弗利特必定出現在北邊**。對**最遠的 2 人**連放 4 次地火 → 從南邊**沿外周往北**引導。(A,BossMod:最遠的 2 名 DPS)
- 火獄之鎖:**二仇 ↔ DPS**;ST 確認自己是二仇;被連到的 DPS 地火排完趕快集合。(A)
- 光輝炎柱:在**東北凹處的最極限邊緣**等它爆炸;緊接著**中央附近落石**,貼邊是為了不被落石打到;依落石順序有時不貼也沒事 → **每次都要刻意貼邊**。(C)
- **雙重地裂斬**:泰坦**必定出現在究極神兵背後的反方向**(拉到東北 → 泰坦在西南)。兩邊都**隨機點名**;**讓究極神兵面朝大部隊**,形狀就固定,**右手邊必有安全區** → 炎柱爆炸後全員**直角往右**,再往外側靠一點躲泰坦。(C)
- **MT 往 3 號、其他人往 2 號**。MT 單吃炸彈後**立刻換坦**、保持二仇;**射線與引爆由換下來的坦克開無敵單吃**,在炸彈倒數快結束時開。(C)
- 飛羽雨 ×2:MT 隨便排,其他人在 2 號標記旁集中排;騎士開神聖領域可以不排。結束後坦克把仇恨拉回來。(C)
